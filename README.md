# Ferretería El Tornillo - Sitio Web Oficial

Página web de una sola página (*one-page*) desarrollada para la **Ferretería El Tornillo**, que permite a los clientes consultar productos de construcción y herramientas, además de ponerse en contacto o solicitar cotizaciones mediante un formulario interactivo.

## 🚀 Demo / Sitio Web Publicado
Puedes ver el proyecto desplegado en el siguiente enlace:
👉 [https://manueltorresee.github.io/ferreteria-el-tornillo/](https://manueltorresee.github.io/ferreteria-el-tornillo/)

---

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica del sitio web.
* **CSS3:** Estilos responsivos, maquetación con Flexbox/Grid y diseño profesional.
* **JavaScript (Vanilla):** Lógica de interacción y validación en tiempo real del formulario de contacto.
* **Git & GitHub:** Control de versiones y alojamiento del repositorio.
* **GitHub Pages:** Despliegue e integración continua del sitio web en la nube.

---

## ✨ Características y Requisitos Cumplidos
1. **Sección Hero / Encabezado:** Bienvenida de impacto con llamada a la acción.
2. **Catálogo de Productos:** 4 tarjetas de productos con imagen, descripción y precio.
3. **Formulario de Contacto:**
   - Validaciones en JS para campos obligatorios (Nombre, Correo, Mensaje).
   - Verificación de formato de correo electrónico.
   - Mensajes de error claros e indicativos para el usuario.
4. **Diseño Responsivo:** Adaptable a dispositivos móviles, tablets y computadores de escritorio.
